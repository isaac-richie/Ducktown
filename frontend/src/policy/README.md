# Pollen policy replays

Pollen Robotics' exact Microduck model, replaying Pollen's **official trained policies** as simulated in MuJoCo.
Generated by [`tools/policy-recorder`](../../../tools/policy-recorder/README.md); nothing here is hand-animated.

| File | What it is |
|---|---|
| `robot.json` / `robot.bin` | Visual model from `microduck_rl` CAD meshes: hidden internals dropped, simplified to ~146k triangles, int16-quantised |
| `clips/*.json` / `*.bin` | Every body's world pose at 50 Hz (int16), recorded with Pollen's own inference code and BAM XL330 actuator model |

Shipped clips (each passed its gate in simulation):

| Clip | Policy | Gate result |
|---|---|---|
| `kick_right` | `ball_kick_right.onnx` | Ball travels 1.34 m, robot stays upright |
| `roulade` | `roulade.onnx` | Full forward roll, lands upright |
| `ground_pick` | `alpha_ground_pick.onnx` | Trunk dips to 8.7 cm, returns upright |
| `stand` | `alpha_stand.onnx` | Holds position (1.4 cm drift over 4 s) |

These are simulation replays, labelled "Simulated" in the UI. They are not recordings of a physical robot.
